Importer vers le staging Supabase

Cette page envoie les entrées vers time_entries_staging uniquement. Firebase et la table métier time_entries ne sont jamais modifiés.

Sélectionne les deux fichiers et connecte-toi avec un profil Supabase Admin.
Le bouton d’import est une écriture contrôlée. Il crée un nouveau batch et conserve les anomalies dans la colonne anomaly_code. Aucun mot de passe n’est enregistré.
